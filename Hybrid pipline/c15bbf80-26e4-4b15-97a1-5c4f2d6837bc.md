Project name: Global Customer Management Platform (GKMP) Project overview The Global Customer Management Platform (GKMP) provides a central solution for managing customer information across different regions, business areas and regulatory responsibilities. The platform is designed to consolidate customer data from multiple legacy systems and provide a unified customer view across the organization. The solution supports German-speaking and English-speaking users and enables seamless integration with existing business applications. Users can access the platform through secure web and mobile interfaces to perform customer onboarding, customer maintenance, contract administration, compliance reviews, and reporting activities. The system must be highly available and ensure the processing of large amounts of data with minimal latency. The platform shall support horizontal scalability and process millions of customer records without performance degradation. Business background The company currently operates several independent applications for storing customer data. This leads to data inconsistencies, redundant data sets, synchronization problems and increased administrative burden. The new platform aims to establish a single source of truth for customer information and improve operational efficiency across departments. Several departments have expressed concerns about data quality, reporting delays and regulatory compliance. Therefore, the organization has decided to implement a modern microservice-based architecture that ensures scalability, maintainability, and resilience. User Story US-001 Customer Search Description As a customer service employee, I want to be able to find customers using different search criteria so that I can quickly retrieve customer information. The system shall provide advanced search capabilities supporting exact and fuzzy matching. Search criteria The user should be able to search for customers using the following fields: Customer number First name Last name Email address Phone number Date of birth Contract number Customer status Acceptance criteria The field "Customer number" must be searchable. The "Last Name" field must be supported. The "First name" field must be supported. Search results shall be returned within three seconds. The hit list must be displayed in a paginated format. The system shall support fuzzy search functionality. The search must ignore uppercase and lowercase. Search filters shall support multiple simultaneous criteria. Search results must be sorted by relevance. User Story US-002 Consent Management Description As a compliance officer, I want to be able to view all customer consents so that regulatory requirements can be reviewed. Functional requirements The compliance officer must be able to display the following information: Consent status Time stamp Origin system Change history Responsible user The system shall preserve historical records for auditing purposes. Acceptance criteria Consent histories may not be processed. Changes must be saved in a revision-proof manner. Audit reports must be exportable as PDF and Excel. The system must log all accesses. Historical records shall remain available indefinitely. Each change must be assigned to a user. Technical Architecture Architecture overview The application follows a microservice architecture consisting of independently deployable services. Each service has a clearly defined responsibility and communicates via standardized REST interfaces. API gateway The API gateway acts as a central entry point for all client requests. Functions: Authentication Authorization Routing Load Distribution API Logging Authentication Authentication takes place via: OAuth 2.0 OpenID Connect Multi-factor authentication The system shall support integration with enterprise identity providers. Core services Customer service Managing customer master data and customer relationships. Contract service Management of all contract information. Notification service Sending emails, SMS messages and system notifications. Audit service Storage of all revision-relevant events. Report service generation of operational and regulatory reports.
